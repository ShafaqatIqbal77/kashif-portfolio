# Kashif Portfolio

A modern, responsive portfolio website built with React, Vite, and TailwindCSS. This portfolio showcases professional services, case studies, team members, and client testimonials with smooth animations and a clean design.

## Features

- **Hero Section**: Eye-catching introduction with call-to-action buttons
- **About Section**: Professional background and mission statement
- **Services Section**: Detailed service offerings with icons
- **Case Studies**: Portfolio of past projects and success stories
- **Team Section**: Team member profiles with photos and roles
- **Testimonials**: Client reviews and feedback
- **Contact Section**: Contact form with validation and WhatsApp integration
- **Regions Section**: Geographic service areas with interactive map
- **Timeline**: Company history and milestones
- **Stats Section**: Key performance metrics and achievements
- **Media Accreditation**: Press mentions and media coverage
- **Theme Toggle**: Dark/light mode support
- **WhatsApp Widget**: Quick contact via WhatsApp
- **Responsive Design**: Fully responsive across all devices
- **Smooth Animations**: Powered by Framer Motion

## Tech Stack

- **React 19**: Modern React with latest features
- **Vite 8**: Fast build tool and dev server
- **TailwindCSS 4**: Utility-first CSS framework
- **Framer Motion**: Animation library for smooth transitions
- **Lucide React**: Beautiful icon library
- **clsx & tailwind-merge**: Utility class management

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## Build

```bash
npm run build
```

The production build will be in the `dist` directory.

## Preview Production Build

```bash
npm run preview
```

## Linting

```bash
npm run lint
```
